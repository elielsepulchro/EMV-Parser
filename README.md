# EMV Parser (Open-Source)

Uma ferramenta leve, em arquivo único (`index.html`), projetada para decodificar e analisar payloads EMV, tanto estáticos quanto dinâmicos (suportando gateways como dLocal, etc.).

## 🚀 Funcionalidades
- Decodificação automática de tags EMV-QRCode por autoridades certificadoras.
- Suporte para payloads.
- Interface responsiva em dark Mode com tailwind CSS.
- Zero dependências de backend (roda inteiramente no navegador).

## 📦 Como Usar
1. Faça o download ou clone este repositório.
2. Abra o arquivo `index.html` em qualquer navegador web moderno.
3. Cole o seu código dinâmico e clique em **Analisar Payload**.
